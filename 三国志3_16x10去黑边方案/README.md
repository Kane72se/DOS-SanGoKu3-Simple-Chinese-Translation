# 三国志3（DOS）16:10 去黑边 —— 方案 A + 方案 B 总结

> 日期：2026-08-16　适用版本：DOS《三国志3》（繁体/简体 DOS 版，模式 12h）

## 1. 问题背景

游戏实际内容只有 **640×400**（画在显存第 40..439 行），却运行在 **640×480**
（VGA 模式 12h）下，上下各多出 40 像素纯黑边。目标：得到 **16:10、无黑边、
方形像素**的画面，且窗口可任意缩放。

密码输入界面是"假输入"：内容不需要看清，回车即可跳过。

## 2. 方案 A：GLSL shader 裁剪（用于 DOSBox-X）

**文件**：`方案-DosBox/san3-16x10.dosbox-x.conf` + `方案-DosBox/san3_crop2.glsl`

**机制**：逐帧识别画面，裁掉上下各 40px 黑边，按 16:10 像素完美整数缩放
显示；密码输入界面自动保持 640×480 4:3 居中。

**环境**：DOSBox-X（在用户桌面的 2024.03.01 版长期使用，2026.08.02 亦可用）。
用法：双击桌面快捷方式"三国志3 16x10 去黑边"，或
`dosbox-x -conf san3-16x10.dosbox-x.conf`。

## 3. 方案 B：原生 640×400 表面 TSR（用于 86Box / 真 DOS）

**文件**：`方案-DOS/SAN3V16.COM`（1933 字节，纯 VPT 版，SHA-256
`77188ca990bb8b09…`）

**机制**：驻留时把 BIOS 视频参数表指针（BDA `0040:00A8`）指向内置的补丁表
（模式 12h 表项：CRTC 起始地址 `0x0C80` = 第 40 行，垂直显示结束 `0x8F` =
400 行）。游戏第一次调用 INT 10h 设置模式 12h 时，BIOS 直接按补丁表编程
CRTC → 模拟器/显卡输出真正的 **640×400 表面，显示显存第 40..440 行 = 完整
游戏内容**。

特点：**零钩子、零按键、零副作用**（不修改任何中断向量，不写文件，不注入
输入）。

**环境**：86Box（真实 VGA BIOS 语义）实测通过——片头、游戏、结局画面全部
16:10 无黑边；密码界面内容被裁掉（回车即过，正常）。真机 DOS / PCem /
ao486 走同样的真实 BIOS 机制，预期同样可用（未逐一实机验证）。

**86Box 用法**：
```text
C:\> cd san3
C:\SAN3> san3v16
C:\SAN3> play
```
`san3v16` 驻留后不打印任何提示、直接回到提示符，这是正常的。

## 4. 关键技术结论（踩坑记录，供后续参考）

1. **"CRTC 写入被 DOSBox 忽略"是坏探针造成的误判**。原探针 `mov ax, imm`
   的立即数顺序写反（`B8 8F 12` 使 AL=0x8F 成了索引、AH=0x12 成了数据），
   16 位 OUT 参数同样写反，立即数端口还写到了 0xD4/0xD5（并非 CRTC 端口）。
   修正后实测：DOSBox-X 2024/2026 **直接写 CRTC 完全有效**（VDE=0x8F →
   `surface consider=640x400`；起始地址 0x0C80 → 画面从第 40 行开始显示）。
2. **DOSBox-X 2026 的 INT 10h 模式设置只采用视频参数表的 VDE（行数），
   忽略起始地址字节**；2024 版则完全不读 VPT。因此纯 VPT 方案在 DOSBox-X
   上只能得到"640×400 窗口尺寸 + 顶部黑带 + 底部内容被裁"，不可交付。
3. **中断钩子路线全部不可行**：钩 INT 10h / 16h / 1Ch 会破坏游戏（卡在文本
   模式或疯狂刷"非法中断 6"）；钩 INT 9（键盘）对合成按键无感、对真实按键
   死机（DOSBox-X 回车瞬间卡死，86Box 按键后失去响应）——链式转发与中断
   上下文写 CRTC 在这两个模拟器里都不安全。
4. **最终成立路线**：86Box 等真实 BIOS 环境会完整遵守视频参数表（含起始
   地址），所以零钩子的纯 VPT 补丁即可实现原生 640×400，无需任何触发。
5. 密码界面裁切在方案 B 中不可避免（文字在显存第 0..45 行），已确认可接受。

## 5. 环境结论

| 环境 | 采用方案 | 状态 |
|---|---|---|
| DOSBox-X 2024 / 2026 | 方案 A（shader） | 可用，日常使用 |
| 86Box（真实 BIOS 语义） | 方案 B（VPT TSR） | 实测通过 |
| 真机 DOS / PCem / ao486 | 方案 B（VPT TSR） | 机制一致，预期可用 |
