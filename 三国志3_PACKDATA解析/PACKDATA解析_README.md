# 三国志3 PACKDATA.DAT 解析

## 结论

`PACKDATA.DAT`（169,054 字节，1992/7/8 存档日期，与 `OPENGRP.DAT` 同期）是《三国志3》DOS 版**原版（1992）开场程序遗留的图形数据文件**。1993 年新版开场程序 `OPEN.EXE` 只在启动时检查它是否存在（数据段文件表第 4 项 `0x1242` → 调用"打开+关闭"做存在性检查），**从不读取其内容**。它属于 KOEI 早期通用的 NPK 式压缩图形格式，与 `OPEN.EXE` 内部解压例程（`0x1C81`，具有 `0x38` 特殊 token、3 字节为一组的位平面结构）同款。

## 文件结构

```
偏移 0      : 4 字节头 = (0x0100, 0x00A8)，即第一张图 256×168（宽×高）
偏移 4      : KOEI NPK 压缩流（第一张图仅 426 字节；后续为更多图形/装饰数据）
```

用游戏自身解压例程（本目录 `decode_packdata.py` 内嵌 8086 指令模拟器）解码后得到 **168 行 × 96 字节**的缓冲区；按 **3 位平面、每 3 字节 8 像素**解读，即为 **256×168、8 色**图形。

## 图像内容

解码出的第一张图主体为黑色背景，**左侧边缘（宽约 27 像素）有一列周期性的装饰花纹/文字状图案**（每 4 像素重复的编织纹样，遍布整个高度）。参考渲染：

![256x168 全图](渲染图/packdata_256x168_v1.png)
![左侧花纹放大](渲染图/packdata_256x168_v1_left64.png)

该图更像是一个**竖条装饰图案或竖排文字条**，可能是原版开场画面左侧的装饰边框/竖排文案。由于 1993 版开场已改用 `OPENGRP.DAT` + `OPEN.NPK`，此文件在游戏中不再显示，具体用途只能从图形内容推断。

## 其它解读尝试

1. 若按《三国志2/本作 GRPDATA》的 4 像素/字面量规则把整份文件当一个连续压缩流解码，会得到 **1,509,700 像素**（310×4870 / 487×3100 / 620×2435 等），且压缩流恰好用完整个文件；但渲染无明显结构，说明那不是该文件的正确读法（`PACKDATA` 用的是带 `0x38` 特判的新式 NPK）。

   ![GRPDATA规则全流 310 宽](渲染图/packdata_grpdata_w310_strip.png)

2. `OPEN.EXE` 反汇编佐证：文件表 `DS:0x17E0..0x17E8 = [0x1224 OPENGRP, 0x1230 KOEI, 0x1239 OPEN.NPK, 0x1242 PACKDATA, 0x124F HAN.16P]`；`PACKDATA` 仅经 `0x6B7B call 0xD9` 做存在性检查。

## 使用

```bash
python decode_packdata.py <PACKDATA.DAT 路径> <输出目录>
```

输出：
- `packdata_256x168_planes.png` —— 第一张图（3 位平面，256×168）
- `packdata_grpdata_w310_strip.png` —— 备选读法（GRPDATA 规则全流）
