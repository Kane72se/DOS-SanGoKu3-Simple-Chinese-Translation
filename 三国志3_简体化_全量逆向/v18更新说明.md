# 三国志3 HAN.16P 全量简体化 — v18 版（2026-08-13）

## 本次修复：替换字“上下缺一行像素”的问题

你实测发现：替换后的简体字（如“请”）上下各少显示一行像素，而繁体原字（請）完整无缺。

### 根因

- 游戏字库每个字是 14 行 × 16 像素（28 字节）。
- 我用来做简体字形的参考字库（HZK16 / SimSun）是 16 行 × 16 像素，
  很多简体字的墨迹占满了全部 16 行（第 0 行和第 15 行各有点，比如“请”的言字旁上点和底部点）。
- v14–v17 采用“裁切”方式，取参考字的 1–14 行 → 正好把第 0 行（顶部点）和第 15 行（底部点）切掉了。
- 原版繁体字是当年专门为 14 行格子设计的，墨迹压满整个格子，所以不缺像素。

### 修复方法：16 行压缩成 14 行（OR 合并），不再裁切

- 把参考字的 16 行按比例压缩进 14 行，相邻两行按“或”合并。
- 全部像素都保留，只是中间略微压缩，上下不再缺行。

以“请”为例（原版請 | v17裁切 | v18压缩）：

```
原版請      v17(裁切)      v18(压缩)
..#........#....   .#...#########..   .........#..#...
...#...#########   ..#......#......   .#...#########..
...
..#..##......##.   ..#...#...#.#...   ..#...#...###...
```

v18 的“请”保留了言字旁的上点（第 0 行）和底部点（第 13 行），完整无缺。

## 验证建议

把 v18 替换进游戏，看主菜单的“开、进、选”和“請選擇”提示，以及武将名里的简体字，
确认上下不再缺行。个别本身就很矮的简体字（如“习”）仍然会显得矮，那是字本身的结构，
原版“習”的第 0 行也是空的，属于正常现象。
